# QA Report - Bug Fix: Malformed GitHub API Response

**Date:** 2026-11-11
**Task:** Fix unhandled exception in `feedback_submission.py`
**Priority:** Bug Fix (High)
**Status:** ✅ FIXED - Ready for QA testing

## Issue Description

When the GitHub API returns a 201 status code but the response JSON lacks the expected "number" field, the application crashes with an unhandled exception:

```
raise Exception("No issue number in response")
```

This can happen when:
- GitHub API returns malformed responses
- Temporary API issues
- Network interruptions during request

## Fix Applied

**File:** `plugins/ag_tech_tooling/feedback_submission.py` (line 453)

**Before:**
```python
raise Exception("No issue number in response")
```

**After:**
```python
# Handle malformed GitHub API response (201 without 'number' field)
error_msg = "GitHub API returned success but no issue number. "
error_msg += "This may be a temporary API issue. Please try again."
QMessageBox.critical(self, "Submission issue", error_msg)
```
