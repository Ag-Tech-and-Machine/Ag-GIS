# Ag-GIS

Farmer-friendly QGIS tooling with a Windows offline installer.

This private repository hosts tested Ag-GIS snapshots and releases. The internal QGIS plugin ID remains `ag_tech_tooling` for upgrade compatibility. Existing farm-data folders remain in place.

End users need repository access to download release assets. Download the offline Windows ZIP, extract all files, save and close QGIS, then run Setup.exe. For updates use Plugins > Ag-GIS > Check for Updates and QGIS's native Install from ZIP.

Validation and clean-machine acceptance status are recorded with each release. Source is GPL-2.0-or-later.
